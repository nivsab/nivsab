## 🧠 Applied AI & Machine Learning

Document understanding, domain-specific evaluation, and retrieval-based assistants.

### [Automated Datasheet Extraction ↗](https://github.com/nivsab/datasheet-extraction)

PDF-to-JSON extraction using synthetic training data and fine-tuned DeBERTa for joint named entity recognition and relation extraction.

> **Published benchmark:** T2-F1 **0.587** on **7 real-world datasheets**, compared with 0.579 for preprocessing alone. T2 requires a parameter-name match and a numeric value within ±10% of the reference. [View results ↗](https://github.com/nivsab/datasheet-extraction#benchmark-results)

`Python` `PyTorch` `DeBERTa` `Synthetic Data` `Information Extraction`

### [CoEval: Hebrew Special Education Case Study ↗](https://github.com/nivsab/CoEval-special_ed)

Domain-specific evaluation of language models on Hebrew communication assessment and intervention-planning tasks.

> **Experiment scale:** **5 models · 40 scenarios · 200 responses · 1,050 valid judge evaluations.** Different models led the two tasks under the study's judge and rubrics. [View results ↗](https://github.com/nivsab/CoEval-special_ed#results)

`LLM Evaluation` `Hebrew NLP` `Rubric Design` `Reproducible Experiments`

### [JACK: Vehicle Assistant & Manual Retrieval ↗](https://github.com/nivsab/Jack_Skill)

A Claude Code skill with structured PDF extraction, manual retrieval, cached vehicle specifications, parts-search tools, and web diagnostic search.

> **Code-level input → output:** `brake pad replacement` → `brake_caliper_torque`, `brake_fluid_type`. The routing function selects the relevant specification fields before retrieval.

`Python` `RAG` `Supabase / pgvector` `Ollama` `Claude Code`
